# Folio privacy notice

Folio performs its reading transformations and article extraction locally in your browser. It has no backend, analytics, advertising, accounts, telemetry, external API calls, or remote code dependencies.

## Data on this device

Chrome local extension storage contains appearance and typography settings, switching preferences, custom palettes, and the normalized origins you explicitly choose for website rules. It can also contain a one-time settings-recovery notice. Chrome session storage contains temporary per-tab enabled/preset overrides and their origin. Article text and reader position exist only in the active page’s memory; they are not stored in a browsing-history or article database. Folio does not read passwords, authentication tokens, cookies, or form values for styling and does not change form submissions.

JSON exports include your chosen website origins and preferences. Keep backups private if those origins are sensitive. Importing a backup does not grant Chrome site permissions. Reset settings through Import & export; revoke permissions through Privacy & permissions or Chrome’s extension controls. Uninstalling Folio removes its Chrome-managed extension storage.

## Website access

Temporary access is granted when you invoke Folio on the active tab. Persistent site access is optional and enables automatic operation on the sites you approve. Broader HTTP/HTTPS access is requested only when you explicitly select “Allow Folio on all websites” and accept Chrome’s permission prompt. Rules are exact-origin; disabled rules allow you to exclude complex or sensitive applications. Browser-protected pages cannot be changed.

Folio does not transmit page content. A website continues to make its own normal requests. Reader images may request their original source URLs; Folio sets no-referrer and never substitutes a third-party content service. Following an original-article or article hyperlink opens its destination normally. Development installation and package audit commands use package registries outside extension runtime.

This release has no publisher-operated contact or support service. A future store publisher must provide its own accurate publisher/contact details and hosted copy of this notice before distribution.
